# Code Royale

Code Royale is a real-time competitive coding game. Two players solve the same coding problem under time pressure. The player who passes all test cases first wins the match.

## Features

The app has these features:

- Ranked and unranked 1v1 matchmaking
- Friend matches with invitations
- Bot battles against simulated opponents
- Practice arena for solo training
- ELO ratings and leaderboards
- Clubs with roles and trophies
- Friends list with live presence
- Player profiles with badges and progress
- Tournament rules page
